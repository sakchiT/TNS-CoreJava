# TNS-Core-Java

Welcome to my Core Java learning and practice repository! This project contains hands-on implementations of essential Java programming concepts, ranging from fundamental data structures to advanced multi-threaded applications and database connectivity. I built this code using the Eclipse IDE to strengthen my understanding of backend development with Java.

## 🚀 Topics Covered

### 1. Java Fundamentals & Data Structures
* **Variables & Data Types:** Understanding primitive and non-primitive types.
* **Typecasting:** Practising implicit (widening) and explicit (narrowing) data conversions.
* **Constructors:** Implementing default, parameterized, and copy constructors.
* **Arrays:** Managing fixed-size elements using single and multi-dimensional arrays.
* **Strings:** Manipulating text efficiently using `String`, `StringBuilder`, and `StringBuffer`.

### 2. Object-Oriented Programming (OOP)
* **Core Pillars:** Encapsulation, Inheritance, Polymorphism, and Abstraction.
* **Interfaces:** Achieving 100% abstraction and multiple inheritance layouts.
* **Method Overloading:** Compile-time polymorphism using different method signatures.
* **Method Overriding:** Runtime polymorphism with parent and child class execution.

### 3. Java Keywords
* **`this`:** Referencing the current class instance and invoking constructors.
* **`super`:** Accessing parent class constructors, methods, and variables.
* **`static`:** Managing memory with class-level variables, methods, and blocks.
* **`final`:** Restricting modification on variables, methods, and class inheritance.

### 4. Advanced Concepts
* **Exception Handling:** Managing runtime errors using `try-catch-finally` blocks and custom exceptions.
* **Multithreading:** Implementing concurrent execution using the `Thread` class and `Runnable` interface.
* **Collections Framework:** Working with dynamic data structures like List, Set, and Map.

### 5. Database Connectivity
* **JDBC (Java Database Connectivity):** Connecting Java applications to relational databases (like MySQL/Oracle).
* **CRUD Operations:** Implementing Create, Read, Update, and Delete operations using `Statement` and `PreparedStatement`.

## 💻 How to Run This Project Locally

### Prerequisites
* Ensure you have the **Java Development Kit (JDK)** installed on your machine.
* (Optional for JDBC) A local relational database management system running.

### Steps to Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
   *(Note: Replace `YOUR_GITHUB_USERNAME` with your actual GitHub username)*

2. **Import into Eclipse:**
   * Open Eclipse IDE.
   * Go to `File` > `Import` > `General` > `Existing Projects into Workspace`.
   * Select the cloned `TNS-Core-Java` folder as the root directory and click **Finish**.

3. **Run a Class:**
   * Expand the project package.
   * Right-click on any class file containing a `main` method.
   * Select `Run As` > `Java Application`.
